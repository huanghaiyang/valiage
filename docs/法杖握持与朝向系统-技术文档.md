# 法杖握持与朝向系统 · 技术文档

> 主题：角色（主角）手持法杖的**握点定位**、**杖身朝向稳定**、**跑动姿态**、调试与验证手段
> 适用范围：`scripts/player.gd`、`scripts/held_staff.gd`、`scripts/character_profile.gd`、`tools/*`
> 相关角色：主角.glb（ARP 系骨架，68 骨）｜动画库：`res://assets/animations/zhujue.tres`（41 条）

---

## 1. 总览

### 1.1 需求

1. 法杖要**自然握在左手里**（不悬空、不穿手、不脱手）
2. 站立时杖身**竖直**
3. 跑动时**不能跟着手臂甩**（旧行为：杖尾朝前，不符合物理）
4. 跑动时杖尾可**略向后拖**（更自然）
5. 所有定位/姿态都要**可调、可验证、可回退**

### 1.2 节点链路

```
主角.glb（实例化）
└─ Visual（缩放 0.01534 → 1.50 m）
   └─ Skeleton3D（68 骨）
      ├─ hand.l（索引 11）
      │  └─ HandSocket（BoneAttachment3D，自动创建）
      │     ├─ HeldStaff（本系统的主角：位置=握点，basis=朝向+缩放）
      │     │  ├─ Model（法杖模型实例，位置由 _place() 精确摆放）
      │     │  ├─ Glow（发光/脉冲）
      │     │  └─ [调试] 绿圆柱 / 橙玻璃球 / 青小球（默认关闭）
      │     └─ [调试] 青小球（挂点坐标系下的握点标记）
      └─ …其他骨骼
```

**要点**：法杖**不是**直接挂在手上，而是挂在 `HandSocket`（BoneAttachment3D）下的 `HeldStaff` 上。
`HeldStaff` 承担两件事：

- **位置** = 握点偏移（手骨本地坐标）
- **basis** = 朝向（旋转）**+ 挂载缩放**（缩放必须保留，见 §11.13）

## 2. 坐标系与单位（最容易出错的地方）

系统里有**三层坐标系**，历史上绝大多数 bug 都来自混用：

| 坐标系 | 定义 | 典型用途 |
|---|---|---|
| **手骨本地（bone-local）** | 以 `hand.l` 为原点、骨骼自身轴为轴 | `staff_grip_local` 的数值、`HeldStaff.position` |
| **HeldStaff 局部** | `HeldStaff` 自身空间，**其 basis 带着杖的朝向与缩放** | `_model.position`（把杖的握点对到原点） |
| **世界（world）** | 场景绝对空间 | 朝向稳定的目标、所有"对不对"的核对 |

### 2.1 单位换算

- 角色缩放：`_auto_scale = 0.01534`（原始高 97.767 → 1.50 m）
- **1 cm ≈ 65.18 手骨本地单位**（即 `1 / 0.01534`）
- 法杖模型自身高（模型局部单位）：`_model_h ≈ 1.75`
- 法杖挂载缩放：`_model.scale ≈ 47.61`（`sc`），父级缩放 `0.01534`
- **世界长度 = `_model_h × sc × _parent_scale` ≈ 1.279 m** ← 这是**回归指标**（见 §10.5）

### 2.2 手骨三轴的世界朝向（站立姿势实测，左手）

```
+X ≈ 世界 (-0.19,  0.04,  0.98)   → 世界"前后"
+Y ≈ 世界 ( 0.98, -0.03,  0.19)   → 沿手骨"朝指尖"  ← 主要旋钮
+Z ≈ 世界 ( 0.03,  1.00, -0.03)   → 世界"上下"（垂直掌心）
```

> 注意：这是**姿势相关**的；换动作后方向会变。所以调 `staff_grip_local` 时应以日志
> `[握点核对] 腕→握点 世界距离 X cm` 为准，而不是记死"X/Y/Z 各管什么"。

### 2.3 三个坐标系混淆的典型事故（历史）

| 事故 | 后果 |
|---|---|
| 用 `_model.position` 承载"手骨本地"的握点 ✗ | 偏移方向被**杖的朝向**旋转 → 杖轴偏出拳心几厘米 |
| 每帧读/写 `global_transform` ✗ | 位置被反复重算（抖动）+ 缩放逐帧累积（越变越大） |
| 用 `basis.orthonormalized()` 换朝向 ✗ | 把 basis 里的**缩放抹成 1** → 法杖撑满全屏 |
| 加载时读 `global_transform` ✗ | 变换尚未就绪 → 打印出 715 cm 之类的假数据 |

## 3. 握点定位（法杖穿过拳心的那一点）

### 3.1 优先级

`player.gd::_attach_held_staff()` 决定握点，优先级：

1. **手调**：`staff_grip_local != (0,0,0)` → 直接用它
2. **自动拳心**：`staff_grip_local == (0,0,0)` → 加载约 0.5 s 后用当前姿势自动标定一次
3. **骨骼算法回退**：上面都失败 → `CharacterProfile.hand_grip_offset()`
   （"腕 → 非拇指手指骨平均方向" × `staff_grip_along`，默认 `1.0`）

**自动标定绝不会覆盖手调值**（历史 bug：见 §11.11）。

### 3.2 "拳心"的定义（自动值）

> 取**当前姿势**下 4 指 × 4 段 = **16 个关节**位置的**平均值**：
> `index/middle/ring/pinky` × `*1_base`（掌骨基）/`*1`（近节）/`*2`（中节）/`*3`（远节）

- **必须包含 `*1_base`**：手指各节关节都在**卷曲外侧**，只用 `*1/*2/*3` 的平均值会落在
  通道**外侧**（实测偏外约 3 cm ✗，表现为"球在指节外、杖在拳中"）
- **必须在姿势就位后算**：加载瞬间骨架还是 rest（手指伸直 ✗），算出来会落到指尖外。
  所以在约 0.5 s（30 帧）后标定一次
- 实测值（主角、站立）：`(-0.692, 5.51, -1.064)`，离腕约 **8.7 cm**

> 局限：这是**一次性快照**。若某些动作把手指卷得更紧/更松，固定握点会与实时拳心出现偏差
> （可用 `debug_fist_sphere` 打开橙色球观察，日志每秒打印两者差值）。

### 3.3 三个预设档位（手调用）

| 档位 | `staff_grip_local` | 离腕 | 说明 |
|---|---|---|---|
| 腕根 | `(0, 0, 0)` | 0 | 表示"用自动" |
| **掌心正中** | `(-0.42, 3.55, -0.07)` | ≈ 5.5 cm | 常用 |
| 指根 | `(-0.85, 7.10, -0.14)` | ≈ 11 cm | 手指夹杖处 |
| 自动拳心 | `(-0.692, 5.51, -1.064)` | ≈ 8.7 cm | `staff_grip_local = 0` 时算出 |

### 3.4 偏移的承载位置（**关键**）

```gdscript
# player.gd（正确 ✓）
held_staff.grip_offset = off      # 仅作记录/日志
held_staff.position = off         # ★ 真正的偏移：HeldStaff 是挂点的子节点 → 坐标系天然正确

# held_staff.gd::_place()（正确 ✓）
_model.position = Vector3(-cx * sc, _grip_y, -cz * sc)   # 只负责"把杖的握点对到 HeldStaff 原点"
                                                          # ★ 不能再加 grip_offset（双重偏移 ✗）
```

原理：`HeldStaff` 的父节点就是 `HandSocket`（手骨）→ 它的 `position` 天然就是**手骨本地坐标**。
而 `_model.position` 处于 `HeldStaff` 局部空间（带着杖的朝向）→ 若把握点放在那里，方向会被杖的旋转带歪 ✗。

### 3.5 半径补偿（默认**关闭**）

曾经的实现：沿"掌心外法线"把杖推出去一个**实测杖半径**，让**杆面贴着掌心**。
用户明确要求**不要**这个行为（"不要让掌心贴近法杖表面"）→ 已关闭：

```gdscript
held_staff.out_dir = Vector3.ZERO          # 关
# held_staff.out_dir = nrm                 # 想恢复"杆面贴掌心"时把注释放开
```

手动微调仍可用：`staff_grip_out`（米，可为负）。

## 4. 杖身在"杖"上的位置

### 4.1 `staff_grip_frac`（0~1）

沿**杖身**（模型 +Y，0 = 底端，1 = 顶端）取握点高度，默认 **0.60**（手握偏上）。
想要"手握杖身下三分之一"（杖头离手更远）→ **0.32**。

### 4.2 摆放算法（`HeldStaff._place()`）

1. 量法杖模型的**合并 AABB**（遍历所有 MeshInstance3D 的局部顶点，支持实例缩放）
2. 在"握点高度"上下开一个**带**（band），取带内顶点的**质心** `(cx, cz)`
   —— 比直接用 AABB 中心更准（法杖有弧线/粗头时）
3. `gy = bb.position.y + grip_frac × bb.size.y`（握点高度，模型局部）
4. 令模型握点落在 `HeldStaff` 原点：

```gdscript
_grip_y = -gy * sc
_model.position = Vector3(-cx * sc, _grip_y, -cz * sc)
```

5. 记下 `_grip_y`（悬浮的基准）

### 4.3 悬浮（hover）

杖身沿世界竖直轻微上下浮动：

```gdscript
_model.position.y = _grip_y + sin(_hover_t) * HOVER_AMOUNT / _world_to_local()
```

> 历史 bug（§11.10）：这里以前写成 `_grip_y + grip_offset.y + …`，在握点移到 `HeldStaff.position`
> 之后会造成**双重偏移**；且早先版本反过来**丢掉** `grip_offset.y` → 第一帧位置对、之后被拉回腕部 ✗。

## 5. 朝向系统

### 5.1 两种模式（`staff_world_stable`）

| 值 | 行为 | 评价 |
|---|---|---|
| `1.0`（默认） | **世界朝向稳定**："松握"——位置跟手，朝向钉在世界空间 | 跑动不甩 ✓，符合物理 ✓ |
| `0.0` | 旧的**刚性跟随**：朝向 = 手骨朝向 | 跑动时随手臂前后甩 ✗（杖尾朝前）|

### 5.2 误差伺服（稳定模式的实现）

**不要**直接用 `global_transform` 反算局部目标 ✗（模型内部还有一层旋转，实测会偏 60° ✗）。
正确做法是**每帧伺服**：

```gdscript
# 1) 目标方向（世界）：世界竖直 + 沿角色朝向的前后倾
run_f = clamp(速度 / RUN_FULL_SPEED, 0, 1)
deg   = world_lean_deg + world_run_lean_deg * run_f      # 正 = 杖头朝前 / 杖尾向后拖
ycol  = (UP * cos(deg) + facing * sin(deg)).normalized()

# 2) 量出当前杖身方向（世界）
cur_dir = _model.global_transform.basis.y.normalized()   # 模型 +Y = 杖身

# 3) 当前 → 目标的旋转，换算到局部，只叠加 k 比例（阻尼）
q           = Quaternion(cur_dir, ycol)
delta_rot   = Basis(q)
par_rot     = 纯旋转(父节点.global_transform.basis)
local_delta = par_rot.inverse() * delta_rot * par_rot
k           = clamp(world_stable * delta * 8.0, 0, 1)    # ≈13%/帧 @60fps，约 0.5 s 收敛
basis       = (纯旋转(basis) * Basis.IDENTITY.slerp(local_delta, k)).scaled(自己缩放)
```

**为什么用伺服**：

- 对**未知的内部旋转**免疫（不用猜模型的朝向）
- 对**缩放**免疫（只写旋转，缩放原样写回）
- **不可能累积/发散**（每帧是"误差驱动"，不是"增量叠加"）
- **不碰 `global_transform`** → 不会重算位置（不抖）、不会累积缩放（不膨胀）

### 5.3 跑动后拖

| 状态 | 目标倾角 |
|---|---|
| 站立 | `world_lean_deg`（默认 0°）→ 竖直 |
| 半速 | 约一半 |
| 全速跑 | `world_lean_deg + world_run_lean_deg`（默认 **12°**）→ 杖头略前、**杖尾向后拖** |

符号约定：**正 = 杖头朝前 / 杖尾向后拖**（沿**角色朝向**，不是世界轴 ✗）。

### 5.4 旧模式（`world_stable = 0`）的标定

`_apply_pose()` 会在**首帧标定一次** `_local_basis`，随后每帧 `basis = _local_basis.scaled(sc)`：

- 优先用档案里的**握持角** `staff_hold_rot_deg`（解自 `Standing Torch Idle 01`）
- 否则用**骨骼 rest 姿势**换算（不用当前动画帧 → 结果稳定、可复现，避免"切杖时正在跑"导致位置概率性错误）
- 再用"世界前倾"作为兜底目标

> 在稳定模式下（默认），这一段**不再写朝向** ✗（否则与世界稳定逻辑每帧互相覆盖 → 稳态仍以跟手为主 + 抖动，见 §11.14）。
> 副作用：`staff_hold_rot_deg` 在稳定模式下**不影响朝向**（位置仍不受影响 ✓）。

## 7. 每帧执行顺序（`HeldStaff._process`）

```
if _need_place:            # 入树后第一帧才量模型（父链 global 变换此时已刷新）
    _place()               #   量 AABB + 切片 → 把杖的握点对到原点
    _build_glow()          #   建发光
    return

_apply_pose(delta)         # 旧模式的朝向标定；稳定模式下**不写朝向**
#if world_stable > 0:      # 误差伺服：把杖身方向拉向"竖直 + 前后倾"
#    只改本节点局部 basis 的旋转，缩放原样写回
#    绝不读写 global_transform

# 悬浮：_model.position.y 上下轻浮（基准 = _grip_y）
# 光效脉冲
```

**关键不变量**：`HeldStaff` 的**位置**永远等于握点（手骨本地）；**朝向**由稳定逻辑或旧标定决定；
**缩放**由挂载时算好，之后只被"原样写回"，绝不重算 ✗。

## 11. 历史 Bug 全记录（现象 → 根因 → 修法）

### 11.1 手指映射语义错位（手部形变）

- **现象**：游戏中手指/手掌形变
- **根因**：Mixamo 手指链是 `proximal/middle/distal/**tip**`（tip 是第 4 段、长度 0、无子骨、**无蒙皮权重**），
  ARP 是 `**metacarpal(*1_base)**/proximal/middle/distal`（4 段且都参与蒙皮）。
  早期用 `seg-1` 规则 → 用 Mixamo 的 tip 去驱动 ARP 的远节 → 形变
- **修法**：**语义 1:1 对位** —— 源第 N 段 → 目标第 N 段（N=1..3），**丢弃第 4 段**，
  `*1_base` 不映射。映射对从 59 → **51**

### 11.2 `-stuff` 动画把姿势当成了 rest

- **现象**：该剪辑下手臂几乎贴着身体（相对旋转 0.0°），动作死板
- **根因**：Blender 里用了 `Apply Pose as Rest Pose`（或编辑模式移动骨骼）→ 姿势被烘成 rest
- **修法**：只摆姿势 → 导出时勾 **Bake Animation**、**关闭 Add Leaf Bones**，绝不"应用姿势为 rest"

### 11.3 库内剪辑全为 LOOP_NONE

- **现象**：待机/跑步不循环
- **根因**：Mixamo FBX 导入后所有剪辑的 loop 模式都是 NONE
- **修法**：烘焙时按**白名单** `LOOP_CLIPS` 设为循环

### 11.4 原地化（in_place）

- **现象**：跑一段又退回
- **根因**：源动画带位移，与项目自身移动叠加
- **修法**：烘焙时把 hips 的 X/Z 锁到首帧（默认开启）

### 11.5 跳跃竖直双计

- **现象**：跳跃高度异常
- **根因**：动画本身抬 hips + 物理抬升叠加
- **修法**：跳跃类剪辑 `zero_pos_y`（把 hips 的 Y 锁死）

### 11.6 劈叉 / 外八

- **根因**：源骨架 rest 与目标骨架 rest 的大腿张角/脚掌偏航不同
- **修法**：`fix_leg_splay`（绕前向轴内收 + 抬髋补偿）、`fix_foot_splay`（脚掌绕世界上轴的偏航归正）
  实测：腿张开 ±10.7°、站姿比 0.53 → 0.21；脚外八 ±28.7° → 归正

### 11.7 删除剪辑的清单未写入

- **现象**：删掉的剪辑"复活"
- **根因**：`bake_all` 没写 `mixamo_sources` 清单 → 增量更新时按文件重建又加回来
- **修法**：`delete_clips` 同时 `clips.erase()`；`bake_update` 跳过 `deleted`；`bake_all` 写清单

### 11.8 握点偏移放错坐标系

- **现象**：杖不穿过拳心（球在拳上、杖从球边擦过）
- **根因**：`grip_offset` 是**手骨本地**，却加在 `_model.position`（HeldStaff 局部，带着杖的朝向）上 → 偏移方向被杖的旋转带歪
- **修法**：偏移改放到 `HeldStaff.position`（父节点就是手骨 ✓）；`_place()` 不再加它

### 11.9 悬浮每帧抹掉握点

- **现象**：进游戏瞬间位置对，之后被拉回"腕部/挂点"
- **根因**：悬浮每帧重写 `_model.position.y`，只用 `_grip_y` → **丢掉握点偏移**
- **修法**：当时先改成 `_grip_y + grip_offset.y`；握点移到 `HeldStaff.position` 后**去掉**该项（否则双重偏移）

### 11.10 自动标定覆盖手调值

- **现象**：**怎么调都在同一个位置**（改检查器/默认值/重启都无效）
- **根因**：`_auto_fist_calib()` **无条件**执行 → 0.5 s 后把 `staff_grip_local` 换成自动拳心
- **修法**：仅当 `staff_grip_local == 0` 时才自动标定；并**取消**"把自动值写回 `staff_grip_local`"的逻辑

### 11.11 编辑器检查器改了没反应

- **现象**：运行中改属性，法杖不动
- **根因**：**游戏跑的是编辑器场景的副本** → 编辑器的检查器**不影响正在运行的游戏**
- **处理**：① 改「编辑器」→ 停止 → 重新运行；② 或调试器面板切 **Remote（远程）** → 选玩家 → 改属性（立即生效）

### 11.12 写 `global_transform` 导致抖动 + 缩放膨胀

- **现象**：跑动时**抖动**，并且法杖**越变越大**
- **根因**：每帧 `global_transform = Transform3D(rot, global_transform.origin)`
  ① 写 global 会**连带重算位置** → 与手骨运动互相打架 → 抖动
  ② 全局↔局部换算夹着缩放（BoneAttachment 换算不干净）→ **缩放逐帧累积** → 膨胀
- **修法**：**永不碰 `global_transform`**，只在**局部 basis**上改旋转，缩放只读自己的并原样写回

### 11.13 `orthonormalized()` 抹掉缩放

- **现象**：法杖**撑满全屏**
- **根因**：`basis.orthonormalized()` 把 basis 里的**缩放抹成 1**（法杖的缩放就藏在里面）
- **修法**：只替换旋转，缩放**原样写回**；用 `_pure_rot()` 精确取出纯旋转

### 11.14 稳定逻辑与旧标定互相覆盖

- **现象**：跑起来**杖尾还是朝前** + 抖动
- **根因**：`_apply_pose()` 每帧写 `basis = _local_basis.scaled(sc)`（跟手 ✗），稳定逻辑每帧只拉 13%
  → 稳态 = 87% 跟手 + 13% 竖直 → 仍以跟手为主 + 两边打架
- **修法**：`world_stable > 0` 时 `_apply_pose` **不写朝向**，由稳定逻辑独占

### 11.15 目标倾斜绕世界轴

- **现象**：角色转身后前后倾方向错
- **根因**：目标 basis 用 `Basis(Vector3.RIGHT, deg)`（绕**世界 X 轴**）
- **修法**：用 `_facing()` 构造目标朝向（与 `_apply_pose` 同一套正交化：`ycol/zcol/xcol`）

### 11.16 直接反算"局部目标"偏 60°

- **现象**：只改局部旋转后，杖身与竖直夹角 **60.4°** ✗
- **根因**：`local = parent_rot⁻¹ × 目标世界旋转` 忽略了**模型自身那层内部旋转**
  （档案握持角就是替它解的）
- **修法**：改用**误差伺服**（量当前杖身方向 → 求旋转差 → 阻尼叠加），对未知内部旋转免疫

### 11.17 加载时读 `global_transform` 得到假数据

- **现象**：日志出现 `腕 → 握点 …距离 715.56 cm` ✗（与自检的 8.67 cm 矛盾）
- **根因**：加载时父链 global 变换**尚未就绪**（Godot 惰性求值）
- **修法**：删掉该打印；可信度量放在**自检时刻**（约 2 s）

### 11.18 调试球太小看不到

- **根因**：1.5 cm 球 + 不透明度 0.35 → 350 px 画面里约 3~4 像素
- **修法**：半径 3.5 cm、不透明度 0.75/0.8；橙色拳心球改成 6.78 cm 玻璃球

### 11.19 用 PowerShell 替换多行代码块

- **现象**：`Parser Error: Expected indented block after "if" block.`
- **根因**：PS 的 `.Replace()` 插入多行块时，**Tab 缩进被吃掉**、且混入 **LF**（文件是 CRLF）
- **修法**：`.gd` 里插多行块**一律用 `edit` 工具**；PS 只用于**单行、纯 ASCII** 的替换

### 11.20 函数插到函数中间

- **现象**：`Identifier "delta" not declared in the current scope`
- **根因**：把 `_pure_rot()` 定义插进了 `_process()` 中间，把"悬浮"那几行挤到函数外
- **修法**：把新函数移到文件后面（`_world_to_local()` 之前）

## 13. 已知限制与待办

1. **拳心是一次性快照**：自动标定在 0.5 s 取一次；动作中手指卷曲变化大时会与实时拳心偏离。
   可选改进：每帧跟随实时拳心（`_update_fist_marker` 已有该计算，可复用）
2. **伺服只有比例项**：`k = world_stable × delta × 8`，无速度项；极端速度下会有轻微滞后
3. **伺服依赖"模型 +Y = 杖身"**：若换一根轴向不同的法杖，需要确认或加轴向配置
4. **`staff_hold_rot_deg` 在稳定模式下不决定朝向**（设计如此）；如需手工握法请设 `staff_world_stable = 0`
5. **半径补偿已关闭**：若某根法杖明显"插进手掌"，用 `staff_grip_out` 手动补，或重新启用 `out_dir`
6. 遗留清理项：未使用的 `主角.tres`；旧 KayKit 包与 `mage` 档案；`-stuff` 剪辑建议按 §11.2 重新导出
7. 跳跃落地：可考虑让跳跃剪辑播完（约 0.3~0.4 s）或做 0.1 s 交叉淡化
