## 1. 已修复（按发现顺序）

| # | 症状 | 根因 | 修法 |
|---|---|---|---|
| 1 | 树干**镂空** | `cull_disabled`（双面）画背面 → 与正面**深度冲突** | 实体改**单面** `render_mode depth_draw_opaque;` |
| 2 | 树干**发白** | `albedo_tex` 缺 **`source_color`** → sRGB 未转线性 → 采样偏亮 | `uniform sampler2D albedo_tex : source_color, hint_default_white;` |
| 3 | 燃烧**太快** | `foliage_burn.burn_time = 2.4` | 草 `7.0` / 树 `18.0` |
| 4 | 一点火就**整片全黑** ✗ 想要"从下往上蔓延" | 木质 shader 用**噪声阈值扫描**（阈值一过就全黑） | 改为**高度前沿**：`front = burn × height_ref` + UV 噪声 ±0.45 米不规则 |
| 5 | 燃烧**闪烁**（余烬带） | 余烬写在高频噪声上的**极窄亮缝**（`exp(-(n-thr)²/w²)`）→ burn 一推进就扫过一批像素 → 逐帧乱跳 | 改为**平滑前沿带** `4·burned·(1-burned)`（纯 burned 的平滑函数，数学上不抖） |
| 6 | 树枝/树**重复点燃**打架 | 每次施法新建燃烧器 → 同一目标多个燃烧器互相覆盖 burn/ash | `burn_node` **防重入**（meta `burning`）+ `_finish` 清理 |
| 7 | 烧完**又长回原样/变绿** | `_finish()` **还原材质** | 保留型（wood）**不还原**；木质钉 `burn=1/ash=0`，叶片等钉 `burn=1/ash=1`（保持消失） |
| 8 | 前沿**忽快忽慢 / 一下全黑** | 材质里 `height_ref = 8.2` 而树实际只有 **4.56 米** → 前沿在 `burn≈0.43` 就越过树顶 | ★ **点火时自动量高**（见 §2） |
| 9 | **烧完由黑变红** | 余烬峰值在 `burned=0.5` 的过渡带；`burn=1` 时仍有部位处于过渡带 → 整片橙红 | 余烬乘 **`(1 - burn)`** → 到顶**完全熄灭** → 纯焦黑 |

## 2. ★ 高度必须"自动量"（关键约定）

shader 里的高度是 **模型空间** 的：
```glsl
varying float v_hgt;
vertex():   v_hgt = VERTEX.y;                 // 模型空间 y（稳定，不受相机影响）
fragment(): float hgt = v_hgt;
```
所以 `height_ref` **必须等于该网格自己坐标系里的高度** —— 手填极易出错（实测：材质写 8.2，树实际 4.53 → 火焰只用前 43% 时间扫完，看上去"飞快/闪烁"）。

**做法**：`foliage_burn._apply_in_shader_burn()` 在复制材质时**用网格局部 AABB 覆盖**：
```gdscript
var ab: AABB = mi.mesh.get_aabb()
var top := ab.position.y + ab.size.y      # 树的实测值 = 4.53
dup.set_shader_parameter("height_ref", top)
print("[燃烧] 自动量高 ✓ height_ref = %.2f 米（%s）")
```
**由此**：换任何模型（树/灌木/别的树）都自动正确，美术不用手填。

> 量高度的脚本参考：`.runtime/probe_aabb.gd`（headless 打印网格 AABB）。
> 实测：`tree_small_02_LOD1` 网格 AABB y = **-0.024 ~ 4.533**（高 **4.557 米**，scale=1.0）。

## 3. 已知残留问题（**暂不修**，用户指示）

### 3.1 燃烧时仍有**轻微闪烁**
- **现象**：树干/树枝燃烧过程中，焦黑/前沿仍有轻微逐帧抖动。
- **已做的缓解**（都有效但未根治）：
  1. 噪声由**世界坐标**改为 **UV**（世界坐标哈希对相机微动/浮点误差极敏感，会整片重随机）；
  2. 高度由**逐像素重建世界坐标**改为**顶点阶段传模型空间高度**（`v_hgt`）；
  3. 余烬由"高频噪声上的窄缝"改为**平滑前沿带**。
- **仍存的可能来源**（未验证）：
  - 控制器**每帧**写 `burn`（浮点抖动 → 前沿带轻微跳动）；
  - 前沿带宽只有 **0.6 米**（`smoothstep(front-0.45, front+0.15, hgt)`）而渐变带较窄，在屏幕上形成移动的高频边缘；
  - GPU 精度 / 大气/雾对薄带的逐帧采样差异。
- **若以后要修，建议顺序**：
  1. 把 `burn` 量化后再写（如 `snapped(burn, 1/512)`）→ 排除浮点抖动；
  2. 前沿过渡带加宽（0.6 → 1.5 米）→ 排除窄带采样跳变；
  3. 用 `noise_tex`（真实噪声贴图）替代程序化哈希 → 彻底去掉逐像素 hash。
- **A/B 判定法**：把 `ember_gain` 设 0 → 不闪 = 余烬带；`noise_scale` 调 0.3 → 不闪 = 高频噪声。

### 3.2 未转换的材质走**另一条路径**（观感不同）
- 控制器对 **`ShaderMaterial`** 目标：**复制该材质**直接写 `burn/ash`（用我们的木质 shader）。
- 对 **`StandardMaterial3D`** 目标（未转换）：改为把自己的 `_mat`（**`burn_foliage.gdshader`**）挂成 **overlay/override**。
- ⇒ **未转换的树枝/树干 = 走 `burn_foliage` 的旧算法**（窄缝余烬 → 更闪、且烧完偏橙红）。
- **结论**：**树干/树枝/树叶三份材质都必须通过插件转换**（`addons/burn_toggle`：检查器下拉或右键），否则观感与修好的那套不一致。

## 4. 排障方法（本轮验证有效）

1. **先埋点，后改代码**（本轮最大教训）：
   - `main.gd::_dump_materials_deferred()`：进游戏后 2s/8s 各打一次"可疑材质"快照（节点名/来源/类型/资源路径/albedo）；
   - `foliage_burn._apply_in_shader_burn()`：打"接管后外观参数是否完整"（材质路径/类型/use_albedo/albedo/base_color）。
2. **一刀切探针**（判断"这份材质到底有没有在画"）：
   - 把 `ALBEDO` 硬写成纯绿 → 屏幕变绿 = 是它在画；不变 = 另有其人；
   - ⚠ 注意：**"把 shader 内容删空后变白"不能作为证据** —— 空/非法 shader 会走 Godot 的**默认白材质兜底**。
3. **零代码 A/B**（改材质参数，不改代码）：
   - `base_color` 改红 → 验证 shader 是否在跑、`use_albedo` 是否生效；
   - `ember_gain = 0` → 验证闪烁是否来自余烬；
   - 燃烧效果选「无」→ 验证问题是否来自燃烧材质（对照原生 `StandardMaterial3D`）。
4. **局部 AABB**（`.runtime/probe_aabb.gd`）→ 量模型真实高度。

## 7. 树叶性能优化 ⇄ 双面渲染的权衡（重要）

### 7.1 之前为"树叶性能"做过的优化（本会话）
`assets/shaders/grass_wind_cull.gdshader`（叶片专用，基于 `grass_wind`）：
1. **去掉 `cull_disabled`** → 单面 → 叶片碎片成本 **−50%**（树叶是最重的 overdraw 源）；
2. **去掉 `depth_prepass_alpha`** → 省掉一整个几何预通道（alpha 裁剪不需要排序，预通道纯开销）；
3. fragment **不再采样 `rough_tex`** → 每像素采样 **3 → 1**（省带宽）。

导出侧（针对叶片几何）：
- **薄片面不参与减面**（薄片保护：V/T ≥ 1.5 且连通块 ≥ 16）→ 叶子不会被切碎；
- **薄片抽稀**（`薄片保留比例`）→ 整片连通块丢弃，直接砍三角形数；
- 合批 `allow_batch` / `prop_visibility`（远处不绘制）/ 贴图分级（叶片 4K → 1K/2K）。

### 7.2 冲突
为了"从不同角度看叶子也不黑"，叶片 shader 现已改为
```
render_mode ..., cull_disabled;          // 双面
if (!FRONT_FACING) { NORMAL = -NORMAL; } // ★ 双面必须翻背面法线（否则背面受光为负 → 发黑）
```
⇒ **第 1 条优化（单面）被撤销**，叶片碎片成本回到 **×2**；第 2、3 条仍然有效。

### 7.3 三条路线（择一）
| 方案 | 内容 | 代价 |
|---|---|---|
| **A（最正宗）** | Blender 里把叶片**复制成双片几何** → shader 保持**单面** | 三角数 ×2，但**无 overdraw 翻倍**，也不依赖法线翻转 |
| **B（现状）** | shader 双面 + 翻法线 | 碎片 ×2，实现简单 |
| **C（折中）** | 双面 + **叶片不投影**（`Cast Shadow = Off`）+ 叶片贴图降 1K | 用阴影/带宽补偿失掉的 50% |

### 7.4 相关需求（未做）
- 玩家要求"树叶双面"⇒ 已按 **B** 实现；若之后要回到 A，需美术侧复制叶片几何；
- 若叶子**整体偏暗**（不是"单侧黑"），那是 `albedo_tex` 缺 `source_color`（同 §1 第 2 条），给叶片 shader 补上即可。
